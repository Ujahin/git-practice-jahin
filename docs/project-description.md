# Project Description

## Purpose

This project demonstrates basic Python programming and Git version control.

## Functionality

The program displays the author's name and the current date. It accepts two numbers from the user, calculates their sum, and displays the result.

## Technologies Used

- Python for programming.
- Git for version control.
- GitHub for remote repository hosting.

## Project Structure

- `src/main.py` contains the main program.
- `src/utils.py` contains the addition function.
- `README.md` explains the project.
- `.gitignore` specifies files Git should ignore.

## Available Functions

### `add(a, b)`
Returns the sum of two numbers.

### `average(a, b)`
Returns the arithmetic mean of two numbers.
